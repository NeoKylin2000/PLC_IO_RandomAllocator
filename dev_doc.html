PLC 实训考核 I/O 随机分配器 — 开发文档

一、项目概述

本项目用于 PLC 实训模拟考试场景，对 5 个 PLC 实训项目的 I/O 点地址进行随机重新分配，避免考生背诵固定地址，保证考核公平性。

数据来源：《新实训题 电子及PLC》文档中 5 个 PLC 实训项目的 I/O 分配表。

分配规则：单选模式，每次只选择一个项目进行随机分配，从八进制地址池中随机抽取（项目内地址不重复）。

二、功能特性

功能说明
项目单选左侧列表通过单选按钮选择一个实训项目，每次只能选一个

五、核心算法

5.1 八进制地址池

PLC 的 I/O 地址按八进制编排：X0-X7, X10-X17, X20-X27 ...

地址池生成函数：

def gen_octal_pool(prefix, count):
    pool = []
    for i in range(count):
        pool.append(f"{prefix}{oct(i)[2:]}")
    return pool
  • 输入地址池：X_POOL = gen_octal_pool("X", 16) → ['X0'..'X7', 'X10'..'X17']
  • 输出地址池：Y_POOL = gen_octal_pool("Y", 16) → ['Y0'..'Y7', 'Y10'..'Y17']
  • 池容量 16，足以覆盖所有项目（最大 12 输入 / 8 输出）

5.2 随机分配

def random_allocate(points, pool):
    n = len(points)
    addrs = random.sample(pool, n)     # 不重复随机抽取
    return list(zip(points, addrs))
  • 使用 random.sample() 保证项目内地址不重复
  • 单选模式下每次只对当前选中项目调用一次

七、使用指南

7.1 操作流程

  1. 启动程序，自动对默认选中项目完成一次随机分配
  2. 左侧通过单选按钮选择需要分配的实训项目（每次只能选一个）
  3. 点击「随机分配」按钮（或按 F5）对当前选中项目执行随机分配
  4. 切换到其他项目后可再次执行随机分配，已分配的结果会保留
  5. 点击「复制当前」/「复制全部」复制结果到剪贴板
  6. 点击「导出TXT」保存分配结果到文件

7.2 快捷键

快捷键功能
F5随机分配（当前选中项目）
Ctrl+C复制当前项目结果
